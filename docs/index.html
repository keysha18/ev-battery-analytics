Comment c'est construit

Chaque étape est testée, et la CI GitHub reconstruit toute la chaîne depuis un dépôt vide.

  1. Fichiers NASA (.mat)34 cellules au format MATLAB brut, téléchargées avec vérification d'empreinte.
  2. Ingestion PythonIdempotente : relancer ne duplique rien. Doublons et fichiers corrompus gérés.
  3. PostgreSQL : raw, staging, martsTransformations et tests dbt. Les valeurs douteuses sont marquées, pas supprimées.
  4. Analyse PythonPic de capacité, pente de perte, genou, prévision de fin de vie et backtest.
  5. API FastAPILecture seule, avec un rôle de base dédié. Chaque prévision porte ses réserves.
  6. Dashboard StreamlitNe lit que l'API, jamais la base.

Une prévision, et ses réserves (B0043)

Pour cette cellule la fin de vie n'est pas encore atteinte : la tendance est prolongée (pointillés) jusqu'au seuil (trait horizontal) et donne une fin de vie vers la décharge 54, intervalle 53 à 55. Cet intervalle est trop étroit : il ne reflète que l'incertitude sur la pente. C'est pourquoi l'API ne livre jamais ce chiffre sans ses réserves.

  • Résultat issu d'heuristiques non calibrées sur une vérité terrain (docs/degradation.md).
  • Extrapolation linéaire : elle prévoit une fin de vie trop tardive si la perte s'accélère et trop précoce si elle ralentit ; le backtest montre les deux cas.
  • L'intervalle ne reflète que l'incertitude sur la pente, pas l'erreur de modèle.
  • Backtest (18 prévisions rejouées sur 6 cellules) : l'intervalle contient la vraie fin de vie dans 5 cas sur 18 (il est donc trop étroit) ; erreur relative moyenne 18 %.

Ce que ce projet n'affirme pas

  • Les seuils (validité des capacités, marge sur le seuil NASA, fiabilité, détection du genou) sont des heuristiques, non calibrées sur une vérité terrain.
  • Le backtest ne porte que sur quelques cellules : ce sont des ordres de grandeur, pas une validation.
  • Les groupes de cellules diffèrent par la température, le courant et la tension de coupure : un écart de dégradation ne s'attribue pas à la température seule.
  • Ce n'est pas un modèle prédictif de production : c'est une démonstration de chaîne de données fiable, qui dit honnêtement ce que les données permettent de conclure.
